# Коуч у хмарі (Supabase)

Коуч (асистент продуктивності) працює лише в Supabase Edge Function `assistant`: перевірки й чат
виконує вона, тож асистент один на всі пристрої і працює, навіть коли конкретний ПК вимкнено.
Таблиці `ft_*`, розклад і тригер створює сам застосунок; тут лише код функції (`functions/assistant/index.ts`).

## Один раз

1. **GitHub → Settings → Secrets and variables → Actions** — додайте два секрети репозиторію:
   - `SUPABASE_ACCESS_TOKEN` — токен з supabase.com → Account → Access Tokens;
   - `SUPABASE_PROJECT_REF` — ref проєкту: частина адреси `https://<ref>.supabase.co`
     (або Project Settings → General → Project ID).

   Після цього workflow `deploy-assistant` розгортає функцію при кожній зміні `supabase/functions/**`
   у `main`. Щоб розгорнути вперше, запустіть його вручну: **Actions → deploy-assistant → Run workflow**.
2. **Supabase → Edge Functions → Secrets** — додайте `ANTHROPIC_API_KEY` (ключ з console.anthropic.com).
   `SUPABASE_DB_URL` Supabase задає сам.
3. Оновіть застосунок на всіх пристроях. Синхронізація з Supabase («Налаштування» → «Синхронізація
   між пристроями») має бути налаштована: щойно Коуча увімкнено, застосунок сам вмикає `pg_cron` і `pg_net`,
   ставить завдання раз на 5 хвилин і тригер на нові повідомлення чату (один раз на пристрій;
   повторний запуск з іншого пристрою нічого не ламає).
4. У розділі **Коуч** у «Налаштуваннях» поставте «Увімкнути асистента», заповніть цілі й натисніть
   «Зберегти» — налаштування підуть у базу (`ft_assistant_settings`), і функція почне працювати.

Ключ Anthropic у застосунку не потрібен: він живе лише в секретах Supabase.
Ключі нікуди не записуються в репозиторій: функцію будить сама база із секретним заголовком
`x-ft-secret`, який зберігається лише в таблиці `ft_assistant_state` (закритій RLS).

## Як це працює

- Застосунок щохвилини відправляє присутність (`ft_presence`) і що було у фокусі (`ft_recent_activity`,
  зберігається 3 години), а при збереженні налаштувань — цілі, правила й розклад (`ft_assistant_settings`).
- Раз на 5 хвилин функція в продуктивні години складає план дня, перевіряє, чи все йде до цілей
  (лише якщо користувач за якимось пристроєм), а ввечері підсумовує день і оновлює свою пам'ять.
- Повідомлення асистента й чат — у `ft_assistant_messages`; застосунок показує втручання в кутку
  активного пристрою. Фокус-режим (`ft_focus`) один на всі пристрої.
- Стан і остання помилка функції — у `ft_assistant_state` (видно на сторінці асистента).
